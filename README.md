# おおさか銭湯 のらりくらり

大阪の銭湯の魅力を紹介する、HTML・CSS・JavaScript製の1ページサイトです。

## ファイル構成

- `index.html`：ページの内容と構造
- `style.css`：デザインとレスポンシブ表示
- `script.js`：メニュー、スクロール、アニメーション
- `images/`：サイト内で使用する画像

## ローカルで確認する方法

`index.html`をブラウザで開くと確認できます。
