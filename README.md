# おおさか銭湯 のらりくらり

大阪の銭湯の魅力を紹介する、HTML・CSS・JavaScript製の1ページサイトです。

## ファイル構成

- `index.html`：ページの内容と構造
- `style.css`：デザインとレスポンシブ表示
- `script.js`：メニュー、スクロール、アニメーション
- `images/`：サイト内で使用する画像

## ローカルで確認する方法

Node.jsが利用できるターミナルで、このフォルダを開いて実行します。追加パッケージのインストールは不要です。

```powershell
node dev-server.cjs
```

ブラウザで http://127.0.0.1:3000 を開きます。HTML・CSS・JavaScriptを編集して保存し、ブラウザを再読み込みすると変更を確認できます。サーバーの停止は `Ctrl+C` です。

ポートが使用中の場合は `$env:PORT=3001` を実行してから起動してください。このサーバーはローカル開発専用です。
